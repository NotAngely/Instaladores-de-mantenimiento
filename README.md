## 🧠 ¿Qué es PSeInt?

PSeInt es una herramienta que permite crear y practicar algoritmos mediante pseudocódigo de una forma sencilla.

## 🔢 Pasos para hacer una suma

1️⃣ Abrir PSeInt y crear un nuevo algoritmo.  
2️⃣ Declarar las variables.  
3️⃣ Pedir los dos números.  
4️⃣ Realizar la suma.  
5️⃣ Mostrar el resultado.  

## 💡 Ejemplo de algoritmo

```text
Algoritmo Suma
    Definir num1, num2, resultado Como Entero
    Leer num1
    Leer num2
    resultado <- num1 + num2
    Escribir resultado
FinAlgoritmo
